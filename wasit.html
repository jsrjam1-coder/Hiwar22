⚙️ إعداد Firebase
أدخل بيانات مشروعك — مرة واحدة فقط
📋 كيف تحصل على البيانات:
1.اذهب إلى console.firebase.google.com
2.أنشئ مشروعاً جديداً
3.من القائمة الجانبية اختر Realtime Database
4.اضغط Create Database ← اختر Test Mode
5.انسخ Database URL من الصفحة
6.من Project Settings ← General انسخ API Key
